# Verify the change address of a PSBT

Verifying the change address of a PSBT is a prudent security step when signing a PSBT generated by your online computer. The reason for this is because there is a small chance that malware could infect the online machine used to generate your transaction. An attacker could swap out the change address in your transaction with their own address, meaning that any funds that would be returned to your wallet as change after the transaction would instead go to the attacker.

This is not a necessary step when doing your test transactions during initial setup, because the change amount is very small, however this extra precaution is worth taking anytime you are signing a PSBT with larger amounts of money.

Note: If you are moving the entire contents of the wallet with a single transaction (sweeping all of the funds in one go), you only need to verify the destination address. There will not be a change address to verify. 

## How to verify change address of a PSBT

To verify the change address of a PSBT on your offline computer, you must have the unsigned.psbt imported onto the desktop of the offline machine. You must then insert any of your key backups and copy the `multisig_watch_wallet` into your `~/.bitcoin/wallets` folder.

Once you have the `multisig_watch_wallet` imported to the proper location, start Bitcoin Core by running this command in the terminal:

```
~/bitcoin-31.1/bin/bitcoind -daemon
```

You will then need to load the wallet:

```
~/bitcoin-31.1/bin/bitcoin-cli loadwallet "multisig_watch_wallet"
```

Then decode the PSBT contents:

```
~/bitcoin-31.1/bin/bitcoin-cli decodepsbt "$(cat ~/Desktop/unsigned.psbt)"
```

Look through the transaction contents and within `tx.vout` you should see two outputs. One is your destination address that you provided when creating the PSBT and the other is your change address.

You should run the following command in the terminal (replacing `$change_address` with the actual change address obtained from `decodepsbt`) to verify that it belongs to your wallet:

```
~/bitcoin-31.1/bin/bitcoin-cli -rpcwallet="multisig_watch_wallet" getaddressinfo "$change_address"
```

In the result of this command you need to look for `"ismine": true`.

If `"ismine": false` STOP! DO NOT PROCEED! You likely have an infected full node computer. 

## Unload the watch wallet after you are finished verifying

Running this command before you attempt to sign the verified PSBT will prevent any errors from occuring when signing the PSBT.

```
~/bitcoin-31.1/bin/bitcoin-cli unloadwallet multisig_watch_wallet
```
