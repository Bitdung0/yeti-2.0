# Start Here

1. This is a manual Bitcoin Core vault, not a product and not customer support

2. Follow the steps as they are written. Do not improvise. 

3. If you need legal recourse, a name branded custodian, or "someone to call" this guide is the wrong tool. Use a regulated brokerage/ETF/trust product instead. However, that is not Bitcoin self-custody, it is a different kind of contract.

4. You do not need to be a Linux user. Ubuntu is a desktop, like Windows. The terminal work is copy the command from the page and paste it, read the output. You do not need to navigate directories by hand.

## What you are setting up

A 3-of-7 air-gapped multisig using Bitcoin Core on two dedicated computers. Keys are generated on an offline machine and backed up to archival discs. Any 3 of 7 discs can spend. Up to 4 can be lost without loss of funds.

The [README](README.md) is the procedure. The FAQ is the design rationale.

## What to do next?

Read the FAQ, then start at section A of the README.
Complete test spends before moving savings into the vault.
